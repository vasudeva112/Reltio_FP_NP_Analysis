Method and how to read the numbers

  • Estimated similarity (0–100) is an analytical score computed from the attributes each match rule uses, with the comparator class configured for that attribute. It is not Reltio's internal match score.
  • Rule evaluation is a Python model of the configured Reltio rule; it is reported separately from the similarity – a pair can be similar and still fail the rule.
  • Labels such as potential false positive or high-confidence missed match are hypotheses for data steward review. Only steward-confirmed pairs are reported as confirmed.
  • Comparators and operators whose exact Reltio behaviour is not documented are implemented as labelled approximations; results depending on them are graded down in confidence.
  • Python results are not claimed to reproduce Reltio until a sample has been verified on the tenant.
